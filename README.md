# tg-assistant

Личный юзербот для Telegram на [Telethon](https://docs.telethon.dev): работает
от моего аккаунта, удаляет сообщения собеседников (у обоих) и отвечает
заготовками на сообщения с ключевыми словами. Управляется через отдельного
бота-пульта с кнопками.

## Пульт

В одном процессе работают два клиента: юзербот (твой аккаунт) делает работу,
а обычный бот из @BotFather служит пультом с кнопками. Пульт слушается только
владельца аккаунта, под которым залогинен юзербот. При первом запуске юзербот
сам нажимает в пульте /start.

- `/menu` открывает меню: «Правила» (кнопкой 🗑 правило удаляется),
  «Заглушённые» (кнопкой снимается заглушка), «Автоответ», «Фильтр слов»,
  «Удалить сообщения».
- Если переслать в пульт сообщение человека, появятся кнопки для него:
  заглушить, удалить последние N, автоответ, фильтр. Если человек скрыл
  аккаунт в настройках пересылки, нужно прислать его `@username`.
- Автоответ и фильтр задаются по шагам: кому (`@username`, `+телефон`,
  пересланное сообщение или «во всех личках») → ключевые слова → текст ответа.
- Те же действия есть текстом: `.mute @user`, `.reply [@user] цена => ответ`,
  `.filter [@user] казино`, `.del @user N`, `.rules`, `.unrule N`, `.help`.

Прямо в переписке работает `.del`: ответом на сообщение удаляет его у обоих,
`.del N` удаляет последние N сообщений собеседника. Остальные текстовые
команды там тоже работают (для этого чата), но удаляются сразу и молча.
Ошибки приходят в пульт. Собеседнику на долю секунды может прийти
уведомление с текстом команды.

Ключи сравниваются целыми словами без учёта регистра. Один и тот же
автоответ уходит в чат не чаще раза в `REPLY_COOLDOWN_SECONDS`, ботам бот не
отвечает. В группах чужие сообщения удаляются, только если ты там админ.
Незаконченный пошаговый ввод сбрасывается при перезапуске.

## ИИ-собеседник

В выбранных личных чатах за тебя отвечает Claude. Включается кнопкой
«🤖 Включить ИИ» на экране человека (после пересылки его сообщения),
в разделе «🤖 ИИ-собеседник» меню или командой `.ai @user`. Выключается
так же или командой `.noai @user`. Пока ИИ включён для чата, автоответы по
ключевым словам там не срабатывают.

- Отвечает через 8 секунд тишины, чтобы ответить разом на несколько
  сообщений подряд. Пока думает, собеседник видит «печатает…».
- Если последним в чате написал ты сам, ИИ молчит. На «ок» и стикеры он
  может не отвечать вовсе.
- Контекст: последние сообщения передаются как есть. Когда их накапливается
  30, старшие 20 сжимаются в короткое резюме, которое хранится в
  `data/rules.json`. Хвост между сжатиями только растёт, поэтому работает
  кэширование промпта.
- Характер ответов задаётся командой `.persona пишу коротко, на «ты», шучу`.
  `.persona` без текста показывает текущий, `.persona -` сбрасывает.
- На прямой вопрос «ты бот?» ИИ честно отвечает, что это автоответчик.

Нужен ключ API с https://platform.claude.com в `ANTHROPIC_API_KEY`. Подписка
Max даёт ежемесячные кредиты на API, Pro их не даёт. Модель задаётся
`AI_MODEL` (по умолчанию `claude-opus-5-5`), глубина размышлений —
`AI_EFFORT` (по умолчанию `low`). Ошибки API (например, кончились кредиты)
приходят в пульт.

## Запуск на сервере (netcup, рядом с expense-tracker)

1. Получить `api_id` и `api_hash` на https://my.telegram.org в разделе API development tools,
   а в @BotFather создать бота (`/newbot`) и взять его токен.
2. На сервере:
   ```bash
   git clone <repo> ~/tg-assistant && cd ~/tg-assistant
   cp .env.example .env   # вписать API_ID, API_HASH и BOT_TOKEN
   chmod 700 data
   docker compose run --rm bot python -m bot.login   # телефон, код, пароль 2FA
   ./deploy.sh
   ```
3. Логи: `docker compose logs -f bot`.

Портов бот не открывает и с nginx expense-tracker не пересекается.

`data/assistant.session` даёт полный доступ к аккаунту: не коммитить, не
копировать. Если сервер скомпрометирован, завершить сессию в Telegram:
Настройки → Устройства.

## Локально

```bash
uv sync
uv run pytest
uv run python -m bot.login && uv run python -m bot.main
```
