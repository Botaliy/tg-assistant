# tg-assistant

Личный юзербот для Telegram на [Telethon](https://docs.telethon.dev): работает
от моего аккаунта, удаляет сообщения собеседников (у обоих) и отвечает
заготовками на сообщения с ключевыми словами.

## Команды

Пишутся от своего аккаунта прямо в чате или в «Избранном». Команда, набранная
в чате, сразу удаляется, а ответ на неё приходит в «Избранное».

| Команда | Что делает |
|---|---|
| `.del` (ответом на сообщение) | удалить это сообщение у обоих |
| `.del N` | удалить последние N сообщений собеседника в этом чате (до 100) |
| `.mute` / `.unmute` | удалять все новые сообщения в этом чате / перестать |
| `.reply цена, прайс => Цены в закрепе` | автоответ на сообщения с этими словами |
| `.filter казино, ставки` | удалять входящие с этими словами |
| `.rules` | список правил |
| `.unrule N` | удалить правило |
| `.help` | справка |

`.reply` и `.filter` из «Избранного» действуют во всех личных чатах, из
конкретного чата только в нём (в том числе в группе). Ключи сравниваются
целыми словами без учёта регистра. Один и тот же автоответ уходит в чат
не чаще раза в `REPLY_COOLDOWN_SECONDS`, и ботам бот не отвечает.

В группах чужие сообщения удаляются, только если ты там админ.

## Запуск на сервере (netcup, рядом с expense-tracker)

1. Получить `api_id` и `api_hash` на https://my.telegram.org в разделе API development tools.
2. На сервере:
   ```bash
   git clone <repo> ~/tg-assistant && cd ~/tg-assistant
   cp .env.example .env   # вписать API_ID и API_HASH
   chmod 700 data
   docker compose run --rm bot python -m bot.login   # телефон, код, пароль 2FA
   ./deploy.sh
   ```
3. Логи: `docker compose logs -f bot`.

Портов бот не открывает и с nginx expense-tracker не пересекается.

`data/assistant.session` даёт полный доступ к аккаунту: не коммитить, не
копировать. Если сервер скомпрометирован, завершить сессию в Telegram:
Настройки → Устройства.

## Локально

```bash
uv sync
uv run pytest
uv run python -m bot.login && uv run python -m bot.main
```
